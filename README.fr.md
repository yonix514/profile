# iwillshowthemthatiwasright

**Monteur vidéo qui code ses propres outils.**

Je monte des récapitulatifs illustrés longs — des centaines d'images sur une voix off de 30 minutes. À la main, ça ne passe pas à l'échelle, alors j'écris les outils qui me manquent : scripts VEGAS Pro en C#, pipelines ffmpeg en Python, et petits analyseurs qui mesurent ce que je devinais avant.

## Projets

| Projet | Ce qu'il fait |
|---|---|
| [**vegas-script-toolkit**](https://github.com/yonix514/vegas-script-toolkit) | 15 scripts VEGAS Pro 20 qui automatisent le montage « images sur voix off » — marqueurs, suppression des silences, sortie batch. |
| [**vegas-scripting-notes**](https://github.com/yonix514/vegas-scripting-notes) | Les pièges de l'API VEGAS Pro absents de la documentation — le code qui échoue, l'échec mesuré, et le correctif. |
| [**edit-style-analyzer**](https://github.com/yonix514/edit-style-analyzer) | Mesure le style de montage d'une vidéo au lieu de le décrire : nombre de plans, durées, coupes franches vs fondus. |
| [**ffmpeg-concat-audit**](https://github.com/yonix514/ffmpeg-concat-audit) | Détecte les deux façons dont ffmpeg modifie silencieusement la durée de votre audio. |
| [**ai-reasoning-doctrine**](https://github.com/yonix514/ai-reasoning-doctrine) | 14 principes pour faire réfléchir les agents IA avant qu'ils affirment — chacun né d'une erreur réelle et mesurée. |
