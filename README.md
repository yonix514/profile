# iwillshowthemthatiwasright

**Video editor who builds his own tools.**

I cut video for a living — long-form illustrated recaps with hundreds of images over a 30-minute voice track. Doing that by hand does not scale, so I write the tools I'm missing: VEGAS Pro scripts in C#, ffmpeg pipelines in Python, and small analysers that measure what I used to guess.

## Projects

| Project | What it does |
|---|---|
| [**vegas-script-toolkit**](https://github.com/yonix514/vegas-script-toolkit) | 15 VEGAS Pro 20 scripts that automate "images over voice-over" editing — marker workflow, silence removal, batch format output. |
| [**vegas-scripting-notes**](https://github.com/yonix514/vegas-scripting-notes) | The VEGAS Pro scripting traps that are not in the documentation — failing code, measured failure, and the fix. |
| [**edit-style-analyzer**](https://github.com/yonix514/edit-style-analyzer) | Measures the editing style of a video instead of describing it: shot count, shot durations, hard cuts vs dissolves. |
| [**ffmpeg-concat-audit**](https://github.com/yonix514/ffmpeg-concat-audit) | Detects the two ways ffmpeg silently changes the duration of your audio, and tells you when it happened. |
| [**ai-reasoning-doctrine**](https://github.com/yonix514/ai-reasoning-doctrine) | 14 principles for making AI agents think before they assert — each one born from a real, measured mistake. |
