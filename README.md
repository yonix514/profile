# Youssef

**Video editor who builds his own tools.**

I cut video for a living — long-form illustrated recaps, hundreds of images over a
30-minute voice track. Doing that by hand does not scale, so I write the tools
instead: **VEGAS Pro scripts in C#**, and **measurement tooling in Python** when I
need to know what an edit actually does rather than what it looks like it does.

My working habit is simple and slightly annoying: **I do not publish a number I
have not measured**, and when a measurement contradicts something I already
said, I publish the correction.

### How I work

1. **Measure before asserting.** No number without a method.
2. **A script that writes needs a script that re-reads.** "It ran" is a claim, not evidence.
3. **Check the output file, not the success message.**
4. **When a measurement contradicts me, the measurement wins** — and I say so publicly.
